# 🚀 FutureMe

**FutureMe** ist ein interaktiver Frontend-Prototyp zur Analyse und Optimierung der privaten Altersvorsorge – konzipiert als Innovation-Pitch für Trade Republic. 

Die App berechnet individuelle Rentenlücken unter Berücksichtigung von Inflation, Zinseszins und Lebenserwartung. Sie schlägt die Brücke zwischen komplexer Finanzmathematik und einer nahtlosen, nutzerfreundlichen Ausführung von Sparplänen.

## ✨ Features

* 📊 **Lebenszyklus-Simulation:** Visualisierung der Anspar- und Entnahmephase (Kapitalverzehr) in Echtzeit.
* 💼 **Ganzheitliche Vermögensaufteilung:** Integriert gesetzliche Rente (DRV), bAV, ETFs, Kryptowährungen, Immobilien und Tagesgeld.
* 🎯 **Smarter Aktionsplan:** KI-gestützte, datengetriebene 1-Klick-Empfehlungen zur Schließung der Rentenlücke (Kaufkraft).
* ⬛ **Trade Republic Integration:** Nahtloser Übergang von der Analyse direkt in die automatisierte Sparplanausführung im bekannten TR-Design.
* 👥 **Persona-basiertes Onboarding:** Integrierte Demo-Profile (Student, Consultant, Projektleiter) für schnelle, realistische Pitches ohne Backend-Anbindung.
* 📱 **Mobile-First UX:** Minimalistisches, App-ähnliches Design mit flüssigen Animationen und Dark-Mode.

## 🛠 Tech Stack

* **Framework:** React + Vite
* **Styling:** Tailwind CSS
* **Charts:** Recharts
* **Icons:** Lucide React
* **UI-Komponenten:** shadcn/ui (angepasst)

## 💻 Lokale Installation & Start

Da es sich um einen reinen Frontend-Prototypen handelt, benötigst du kein Backend oder Datenbanken. 

### Voraussetzungen
Stelle sicher, dass [Node.js](https://nodejs.org/) auf deinem Rechner installiert ist.

### 1. Abhängigkeiten installieren
Öffne das Terminal im Hauptverzeichnis des Projekts (wo die `package.json` liegt) und installiere die Dependencies.
Nutze dafür deinen bevorzugten Package-Manager (`npm`, `yarn` oder `pnpm`):

```bash
npm install
# oder
pnpm install

npm run dev
